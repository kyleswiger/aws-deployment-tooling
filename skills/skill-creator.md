# Skill Creator

A generic guide for building and maintaining Gemini CLI skills.

## Objectives
- Standardize the creation of new skills.
- Provide templates for SKILL.md and associated metadata.

## Workflow
1. Define the skill's purpose and scope.
2. Draft the SKILL.md file with expert instructions.
3. Test the skill in a sandbox environment.
4. Deploy the skill to the local or remote extensions directory.
